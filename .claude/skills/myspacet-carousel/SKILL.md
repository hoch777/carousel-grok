# myspacet-carousel

Карусели для **@myspacet_ai**. Светлая editorial-система. Не тёмная. Не шаблонный AI-слайд.

Агент: прочитай этот файл целиком до кода. Сначала токены и запреты, потом вёрстка.

---

## 0. Кто говорит

- Автор — **девушка**. Голос: «пользуюсь **сама**», «я сижу в локации X».
- Обращение к читателю: «ты», не «вы», если не попросили иначе.
- Язык слайдов: **только русский**. Исключения: названия брендов и команд (`Claude`, `VS Code`, `VPN`, `npm`).
- Никаких калек: не «сижу на Казахстане», а «сижу в локации Казахстан». Не «руки для браузера», а нормальная фраза.
- Ник везде: `@myspacet_ai`.

## 2. Токены (не выдумывать другие)

```
--bg:        #F4F4F2    /* фон слайда, не #fff */
--surface:   #FFFFFF    /* карточки */
--fg:        #111111
--muted:     #5A5A5A    /* обычный текст тоньше и серее */
--orange:    #FF6B2C    /* единственный акцент */
--orange-soft:#FFF0E8
--sage:      #6B8E6B
--sage-soft: #EBF1EB
--green:     #2E9B5E
--green-soft:#E6F6EC
--red:       #E03E3E
--red-soft:  #FDECEC
--border:    #E8E8E6
```

Шрифт: **Plus Jakarta Sans**. Не менять семейство, пока явно не попросили.

- Заголовок: 24–26px, weight **800**, tracking tight, line-height 1.12, `text-wrap: balance`
- Акцент в заголовке: одно слово `color: var(--orange)`
- Лида: 13px, weight **400**, line-height 1.5, muted
- Карточка title: 12px, weight 600
- Карточка body: 11px, weight 400, muted
- Eyebrow: 10px, weight 600, uppercase, letter-spacing 0.14em, muted
- Теги: 10px, weight 600
- Сглаживание: `-webkit-font-smoothing: antialiased`

## 3. Архитектура слайда (сетка)

```
┌─────────────────────────────┐  420×525
│ eyebrow                     │  pt 24, px 28
│ H1                          │
│ lead                        │
│                             │
│ cards / flow / terminal     │  flex-1, gap 12
│                             │
│ [last block sits on bottom] │  last-child: margin-top auto
│                             │
│ ████░░░░  3/9               │  progress + counter
│                         03  │  WATERMARK only — see §4
└─────────────────────────────┘
```

**Жёстко:**

1. `display: flex; flex-direction: column; overflow: hidden` на слайде.
2. Контент `flex: 1; padding: 12px 28px 56px` (низ чистит прогресс-бар).
3. **Последний блок** (`margin-top: auto`) прижат к низу. Так сетка не «уезжает вверх».
4. Карточки: белые, `border: 1px solid #E8E8E6`, radius 12–14px, padding 12px, лёгкая тень `0 1px 2px rgb(17 17 17 / 0.04)`.
5. Сетка карточек: CSS Grid, не процентный flex. `gap: 8px`.
6. Стрелка свайпа справа на всех, **кроме последнего**.
7. Прогресс: трек 3px `rgb(17 17 17 / 0.08)`, заливка `#FF6B2C`, счётчик `n/total` 11px muted.

Не absolute-хаки для основного контента. Не равные три колонки ради «красоты», если контента два.

## 4. Водяной знак 01–09 — это ДЕКОР

Цифры **не элемент шапки**. Не конкурируют с заголовком. Не толкают сетку.

```
position: absolute
right: -12px
bottom: 8px
z-index: 0          /* КОНТЕНТ выше, z-index 1 */
font-weight: 800
font-size: 200px
line-height: 1
letter-spacing: -0.04em
color: rgb(255 107 44 / 0.10)   /* ~10% */
pointer-events: none
tabular-nums
format: 01, 02, … 09   (padStart 2)
```

Запрещено:

- Ставить номер в одну строку с заголовком
- Opacity ≥ 20% (тогда это уже UI, не намёк)
- Размер < 140px (тогда это бейдж, не водяной знак)
- Менять шрифт номера на другой family

## 5. Иконки

**Никогда** не рисовать буквы / эмодзи / 4-лучевую звезду «от себя».

| Тип | Источник |
|---|---|
| UI (замок, щит, галочка, стрелка, bookmark, terminal, alert) | **Lucide**, stroke 2.2, size 14–16 |
| Claude | Официальный **terracotta burst** `#D77655`. Это органический 6-лучевой всплеск. **Не** 4-лучевой ромб Gemini |
| VS Code | Официальный шеврон `#0078D4` |
| Dolphin Anty | Фиолетовый скруглённый квадрат + белая **D** (не R) |
| Playwright | Три круга green / red / blue |
| Прочие бренды | Simple Icons / официальный SVG |

Одна семья UI-иконок на всю карусель. Брендовые логотипы — своими цветами.

## 6. Компоненты

**Eyebrow** — маленькая категория: `шаг 1`, `без лишних обещаний`.

**H1** — 1–2 строки. Одно слово оранжевым.

**Card** — иконка + title + 1–2 строки muted.

**Tag** — `платно` / `мин. тариф` / `стабильно` на soft-фонах (orange-soft, green-soft, red-soft).

**Flow** — пилюли + стрелка Lucide `ArrowRight`. Для «хорошо / плохо» две карточки.

**Terminal** — моно, три точки окна, команды. Примечание к терминалу — **тёмная плашка** `#111` + светлый текст, не бледная серая.

**Save bar** — orange-soft, иконка Bookmark, призыв сохранить.

**CTA last slide** — тёмная плашка `#111` + `@myspacet_ai` оранжевым. Стрелки свайпа нет.

## 9. QA — агент сам, пользователя не гонять

Перед сдачей проверь скринами каждый слайд:

- [ ] Светлый фон `#F4F4F2`, не тёмный
- [ ] Заголовок не пересекается с номером
- [ ] Номер — водяной знак снизу, ~10%
- [ ] Последний блок сидит над прогресс-баром, низ не пустой «случайностью»
- [ ] Claude ≠ Gemini-звезда
- [ ] Dolphin = D, не R
- [ ] Нет английских фраз кроме брендов
- [ ] Женский род: сама, не сам
- [ ] Контраст текста на карточках читаемый
- [ ] 4:5, прогресс совпадает с индексом

Сломал сетку — чини, не спрашивай «посмотри, ок?».

## 10. Экспорт

Превью верстать при **420×525**. PNG: Playwright `device_scale_factor = 1080/420`, clip 420×525. Не ставить viewport 1080×1350 — поедет типографика.

HTML для экспорта писать файлом (Python `Path.write_text` или обычный файл в репо), не heredoc.

Картинки пользователя — только `data:` URI в `<img>`, не `background: url(data:...)`.
